# Changelog

## 1.2.0 — 2026-08-30

- Added a screen picker and support for every connected monitor.
- Kept overlays above Chrome and other apps more reliably.
- Changed slideshows to use Random, Favorites, My media, or GIFs.

## 1.1.1 — 2026-08-30

- Added 5, 10, 30, and 60 second slideshow speeds.

## 1.1.0 — 2026-08-30

- Added an optional local photo slideshow.
- Added previous, pause/play, and next slideshow controls.
- Slideshow choices are temporary and never uploaded.

## 1.0.0 — 2026-08-30

- First Windows desktop version.
- Added a picker with 12 licensed meme images and 12 licensed GIFs.
- Added the global `Ctrl+Shift+K` Random shortcut.
- Added custom local media and favorites.
- Added draw, move, resize, replace, lock, remove, clear, and tray controls.
