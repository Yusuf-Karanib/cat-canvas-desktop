# Contributing

Small improvements are welcome.

1. Fork the repository.
2. Make one focused change.
3. Run `npm test`.
4. Test it on Windows.
5. Open a pull request and explain what changed.

By submitting a contribution, you confirm that:

- You created it or have permission to submit it.
- Submitted code is released under this project's MIT License.
- Submitted media has clear redistribution rights.
- New media includes its creator, source, license, and changes in `ASSET-CREDITS.md`.

Do not submit media copied from search results, social media, or GIF websites unless its license clearly permits redistribution.
