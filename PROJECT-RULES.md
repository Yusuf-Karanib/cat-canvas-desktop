# Project rules

These rules cover all media, including cats, dogs, birds, reptiles, images, and GIFs.

## Official project

The maintainers control only the official Cat Canvas Desktop repository and releases. Media with unclear rights may be rejected or removed.

## User-added media

Users must own their added media or have permission to use it. User-added media stays on the user's computer and is not published by Cat Canvas Desktop.

## Contributions

Contributors must have the right to submit their code and media. Submitted code uses the MIT License. Submitted media must include its creator, source, license, and changes in `ASSET-CREDITS.md`.

## Forks

The MIT License allows people to copy and change the code. Forks are independent projects controlled by their owners. They must not claim to be official Cat Canvas Desktop releases or suggest that this project approves their changes.

Fork owners are responsible for their changes, users, privacy statements, downloads, and media. They must keep every notice required by media they retain.

## Copyright concerns

If official Cat Canvas Desktop media appears to use your work incorrectly, open a copyright report in this repository. Include the file, original source, and a simple explanation. Do not publish private identity documents.

The maintainers may remove disputed media while the concern is checked.

## No warranty

The software is provided without a warranty, as explained in the MIT License. These rules are not legal advice and do not replace applicable law or media licenses.
