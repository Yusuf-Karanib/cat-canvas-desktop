# Roadmap

## Version 1

- Windows app with a tray icon
- Global Random shortcut
- User-recorded Random shortcut with a safe default
- Optional Start with Windows setting
- First-time quick guide that can be reopened later
- Licensed built-in cats and local custom media
- Slideshows using Random, Favorites, My media, or GIFs
- Draw, move, resize, replace, lock, remove, and clear
- Temporary overlays on any connected monitor

## Good next improvements

- More ways to move placed media between monitors
- Small optional animal packs
- Better keyboard accessibility
- Signed Windows releases if the project grows

## Not planned

- Accounts
- Uploads
- AI features
- Cloud storage
- Tracking or advertisements
