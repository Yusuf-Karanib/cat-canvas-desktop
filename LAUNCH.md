## Reddit: r/SideProject

**Title**

I made an open-source Windows app that puts cats over any app

**Post**

I started Cat Canvas because I like cats and wanted a small open-source project I would actually use.

You pick a cat image, GIF, favorite, or slideshow, draw a box anywhere on any connected screen, and the cat stays above your other apps. You can move, resize, replace, lock, or remove it. Everything stays local, with no accounts or cloud services.

It is built with Electron, released under MIT, and the Windows download is on GitHub. I would like honest feedback about whether the picker is easy to understand.

https://github.com/Yusuf-Karanib/cat-canvas-desktop

**Title**

Cat Canvas Desktop: an MIT-licensed Windows overlay for images and GIFs

**Post**

I built Cat Canvas Desktop, a small Electron app that lets users draw temporary image or GIF overlays above any Windows app.

It supports multiple monitors, local custom media, favorites, slideshows, and user-recorded shortcuts. It has no accounts, analytics, uploads, ads, or runtime network requests.

The code is MIT licensed. Bundled media has separate attribution and license records. The repository also includes contribution, privacy, security, and project-rule documents.

Feedback and contributions are welcome:
